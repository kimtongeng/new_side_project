1 STEP 1: Full System Backup (Crucial)

Important: Always create a full backup of both your MySQL database and existing codebase before applying any update.
  • Database Backup: Export database via phpMyAdmin or SSH:
    mysqldump -u [db_user] -p [db_name] > backup_before_update_$(date +%F).sql
  • Files Backup: Create an archive of your current project root directory.

4 STEP 4: Clear Laravel System Caches

Clear compiled caches so Laravel immediately loads all updated routes, controllers, and Blade templates:

php artisan config:clear php artisan cache:clear php artisan view:clear php artisan route:clear

Note for Shared Hosting (without SSH): Go to Admin Panel → Settings → Clear Cache.

5 STEP 5: Roles & Module Permissions Configuration

  1. Go to User Management → Roles → Click Edit on Admin / Manager roles.
  2. Configure permissions for:
    • User Management: Verify user view, create, edit, and status update access.
    • Essentials & HRM: Enable permissions for Attendance, Leaves, Payroll, To-Do Tasks, Knowledge Base, and Reminders as needed per role.
  3. Click Update to save role changes.

6 STEP 6: Cashier & Client Browser Refresh

Perform a hard browser reload to ensure the new filter scripts, DataTables bindings, and CSS styles load immediately:

  • Windows / Linux: Press Ctrl + F5 or Ctrl + Shift + R
  • Mac: Press Cmd + Shift + R

🔄 Rollback Procedure

In the unlikely event of an issue:

  1. Restore the database from your pre-update .sql backup.
  2. Restore previous project files from your backup zip.
  3. Run php artisan cache:clear && php artisan view:clear.
